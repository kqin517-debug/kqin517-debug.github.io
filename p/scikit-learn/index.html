Python 机器学习的标准库，分类、回归、聚类和评估工具齐全。
详细介绍

最常用的 Python 机器学习库，统一了分类、回归、聚类、降维和模型评估的接口。文档质量高、示例多，适合先建立完整的建模流程，再替换成更复杂的模型。做机器学习预测模型时，通常从它开始搭第一版基线。
