一句话简介
用纯 Python 写数据应用，脚本一存盘页面就自动刷新。
详细介绍

把 Python 脚本直接变成 Web 应用，不用写前端，滑块、图表、上传控件都有现成组件。改代码后页面自动重载，非常适合做数据探索和模型演示。它默认单机运行，要做复杂权限或多页面的大型系统，需要额外设计。
